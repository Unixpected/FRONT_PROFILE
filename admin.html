Publish settings

Needed once. This panel sends your changes straight to your GitHub repository, and GitHub Pages updates the live site in about a minute.

How do I get a token?
  1. On GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens, then Generate new token.
  2. Under Repository access choose "Only select repositories" and pick this site's repository.
  3. Under Permissions set Contents to "Read and write", then generate and paste the token here.

The token is saved only in this browser. Without it nobody can publish changes, so keep it private.
